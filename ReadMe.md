# Vault AI Toolkit — Система «Координаты Смысла»

**Vault AI Toolkit** — это плагин для Obsidian, который превращает ваше хранилище из хаотичного набора файлов в живую, семантически связанную базу знаний. Он использует AI для анализа, категоризации и дедупликации заметок, позволяя вам сосредоточиться на творчестве, а не на администрировании.

## 📊 Текущий Статус Проекта

Этот документ описывает как уже реализованную функциональность, так и амбициозное видение проекта. Для ясности все возможности разделены на две категории: **"✅ Реализовано"** и **"🎯 Планы Развития"**.

## ✅ Реализовано

### 1. Интеллектуальный Анализ Метаданных
- **Автоматическое присвоение "Координат Смысла"**: Плагин анализирует текст и добавляет в YAML-шапку файла метаданные:
  - `tags`: Тематические теги
  - `project`: Принадлежность к проекту
  - `content_type`: Тип контента (эссе, практика, анонс и т.д.)
  - `status`: Стадия жизненного цикла (идея, черновик, завершено)
  - `quality_score`: Оценка ценности текста (от 1 до 10)
  - `summary`: Краткое резюме содержимого
  - `sense_id`: Уникальный "смысловой отпечаток" в виде кликабельной ссылки для поиска похожих заметок.
- **Массовая обработка**: Команды для анализа всех файлов в выбранной папке.

### 2. AI-Категоризатор
- **Предложение пути для перемещения**: На основе метаданных файла AI предлагает наиболее подходящую папку (`suggested_path`) в соответствии с вашей структурой в рубрикаторе.

### 3. Visual Note Browser
- **Мощный интерфейс для навигации**: Позволяет просматривать заметки в виде интерактивных карточек или ленты.
- **Режимы отображения**:
  - **Сетка (`grid`)**: Компактное представление заметок в виде карточек.
  - **Лента (`feed`)**: Вертикальный список с возможностью развернуть и прочитать полный текст заметки, не покидая браузер.
- **Фильтрация и Сортировка**:
  - Поиск по тексту в названии и содержании.
  - Фильтры по типу контента, статусу и проекту (на основе метаданных в видимых файлах).
  - Сортировка по пути, дате создания/изменения, размеру и `quality_score`.
- **Интерактивные карточки**:
  - Отображение ключевых метаданных.
  - Кликабельные теги для быстрой фильтрации.
  - Кнопка для поиска похожих файлов по `sense_id`.
- **Массовые операции**:
  - Выделение нескольких файлов (включая Shift+Click для выбора диапазона).
  - Принятие всех предложений AI по перемещению для выбранных файлов.
  - Удаление выбранных файлов.
- **Специальные режимы**:
  - Открытие браузера для конкретной папки.
  - Отображение результатов поиска похожих файлов.

### 4. Поиск Дубликатов
- **Точные дубликаты (100% совпадение)**: Команда для поиска и удаления полностью идентичных файлов в папке.
- **Семантически похожие заметки**: Команда для поиска смысловых дубликатов на основе `sense_id`. Создает интерактивный MD-отчет, где можно просмотреть группы похожих файлов.

### 5. Глубокая Настройка
- **UI Настроек**: Все ключевые параметры, словари и промпты настраиваются через графический интерфейс.
- **Редактируемая Таксономия**: Возможность добавлять/изменять/удалять свои типы контента, статусы, проекты.
- **Редактор Промптов**: Встроенный редактор для изменения системных и пользовательских промптов, используемых AI.
- **Импорт Рубрикатора**: Структура папок для AI-категоризатора загружается из файла `data/rubricator.yaml`.

### 6. Интеграция с Obsidian
- **Команды и Ribbon-меню**: Быстрый доступ к основным функциям.
- **Контекстные меню**: Действия для файлов (проанализировать, найти похожие) и папок (открыть в Visual Browser).
- **`Ctrl+Click` по папке**: Быстро открывает ее в Visual Note Browser.
- **Протокол `obsidian://`**: Поддержка кастомных ссылок для запуска действий (например, поиска похожих по `sense_id`).

## 🎯 Планы Развития

### 1. 🧠 AI Sidebar - Умная Панель Метаданных
Ключевая запланированная функция, которая выведет взаимодействие с метаданными на новый уровень.
- **Автоматическое отображение**: Панель будет показывать метаданные для текущего активного файла.
- **Список похожих заметок**: Автоматически находить и отображать 3-5 семантически близких файлов.
- **Быстрые действия**: Кнопки для перемещения файла по рекомендации AI, объединения с похожими, редактирования и очистки метаданных.
- **Интерактивные элементы**: Кликабельные теги, изменяемый рейтинг качества, смена статуса через dropdown.

### 2. Улучшения Visual Note Browser
- **Многоуровневая фильтрация**: Более сложные фильтры (диапазоны дат, размеров, качества; исключение тегов).
- **Визуализация иерархии**: Возможность отображения древовидной структуры папок внутри браузера.
- **Drag & Drop**: Перетаскивание файлов между категориями для быстрого перемещения и изменения метаданных.
- **Производительность**: Внедрение виртуализации для плавной работы с тысячами файлов в режиме ленты.

### 3. Расширение Функционала AI
- **Синтез заметок**: Реализация логики объединения нескольких похожих заметок в один мастер-документ с помощью AI.
- **Улучшенный Процесс Анализа**: Добавление интерактивного лога обработки, возможности ставить на паузу и возобновлять массовый анализ.
- **Поддержка локальных моделей (Ollama)**: Интеграция локальных LLM для выполнения некоторых задач без отправки данных в облако.

### 4. Улучшения UX
- **Дашборд Аналитики**: Визуализация статистики по хранилищу (количество заметок по типам, статусам, динамика качества).
- **Экспорт/Импорт Настроек**: Удобное сохранение и перенос полной конфигурации плагина.

## ⚙️ Настройка Таксономии
- **Словари**: Управляются через UI настроек плагина.
- **Структура папок (Рубрикатор)**: Находится в YAML-файле `.obsidian/plugins/vault-ai-toolkit/data/rubricator.yaml`. AI использует его для предложений `suggested_path`. Вы можете редактировать файл напрямую или импортировать эталонный через настройки плагина.

## 🔗 Системные Требования
- Obsidian версии 1.0.0+
- API ключ Google Gemini
- Рекомендуется: 4+ ГБ RAM для больших хранилищ (1000+ файлов)
